# Cover logos

These local assets identify the authors' institutions on the presentation cover.
They are bundled so the presentation does not need an internet connection to show them.

- `cornell.svg`: [Cornell University website asset](https://www.cornell.edu/assets/core/images/logo-red.svg), referenced by the university's website stylesheet.
- `ibm.svg`: [IBM positive 8-bar artwork](https://www.ibm.com/brand/experience-guides/developer/b1db1ae501d522a1a4b49613fe07c9f1/01_8-bar-positive.svg). Only the SVG viewport was tightened to remove surrounding white padding; the original artwork and colors are preserved.
- `sandia.svg`: [Vector Sandia logo from Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Sandia_National_Laboratories_logo.svg), whose file page attributes the source to Sandia National Laboratories. Unreferenced definitions (including unused raster masks) were removed, and an explicit viewport was added. Visible artwork and its clipping paths are preserved; the bundled file contains no raster images and stays sharp when enlarged.
- `sandia.png`: Previous low-resolution [Sandia logo asset](https://opencsp.sandia.gov/app/uploads/sites/274/2024/09/sandia_logo_from_proposal_template.png), retained for reference; the cover now uses `sandia.svg`.

Retrieved October 7, 2026. Logos remain the property of their respective institutions.
